# Designer Playbook

Inspect existing screens and design tokens. Specify user journeys, loading/error/empty states, responsive behavior, keyboard access and visible focus states. Prefer the existing component and icon system.

This pipeline stage produces design specifications, not file edits. Hand off exact component owners, token names, interaction states and measurable acceptance criteria to the frontend engineer. Distinguish inspected behavior from mockup assumptions.
